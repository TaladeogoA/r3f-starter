# R3F Starter

A reusable React Three Fiber starter built with Vite and TypeScript.

## Included

- React Three Fiber and Drei
- TypeScript
- Leva controls
- Suspense
- Orbit controls and environment lighting
- Development-only performance stats
- Soft shadows
- ACES filmic tone mapping and sRGB output
- Structured folders for components, hooks, shaders, utilities, and assets

## Development

```bash
npm install
npm run dev
```

Add project-specific 3D content in `src/Experience/Scene.tsx`.
